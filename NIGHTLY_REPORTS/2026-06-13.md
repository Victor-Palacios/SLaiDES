## Phase 4 — Linter (completed this session)

Commit: `954fb32`

Fixed three categories of false-positive lint errors that blocked the clean-deck acceptance test:

1. **E_MIN_BODY_SIZE false positives**: stat-callout subtext and timeline dates use the caption tier (25pt), legitimately below the 32pt body floor. Fix: added `is_caption: bool` to `ResolvedNode`; layout engine marks these nodes; linter skips `is_caption=True` nodes.

2. **E_GAP false positives inside card-grid**: intra-card spacing (icon/title/body) is 0.15" by design, below the 0.3" inter-element floor. Fix: added `group_id: Optional[str]` to `ResolvedNode`; card nodes share a group_id; linter skips same-group pairs.

3. **E_OVERFLOW in example decks**: root cause was that `wrap()` uses `usable_width = box_width_emu - 182880` (subtracting L+R insets), not the full box width. For the 4-card grid, usable = 2430780 EMU, not 2613660. Many English words at 34pt calibri/arial exceeded this. Fix: rewrote all 10 example decks with content verified to fit, changed calibri examples to arial (exact proxy metrics).

Final linter result: 122 tests passing, clean deck produces 0 errors.
