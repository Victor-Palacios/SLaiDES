# Research paper consolidated summary

This directory contains the consolidated research-paper PDF artifact:

- `research-paper-summaries.pdf` — includes each verified reference from `docs/REFERENCES.md` and now reserves a visual-placement block for every paper so figures, diagrams, screenshots, tables-as-visuals, and captions can live directly beside the relevant paper summary.
- `build_research_summary_pdf.py` — regenerates the consolidated PDF with the visual insertion index and per-paper visual slots.

The visual pass records captions that were identifiable during this update and leaves explicit insertion points for any source-paper visuals that require the original PDF/image assets to be added later.
