## Designs completed — commit `95c89c6`

All quantitative content is rendered with **measurable rects only**, per the Phase 9
determinism rule (no freehand marks; the linter still proves fit):

- **`kpi-grid`** — a 2–3-column dashboard of cells; each cell is a header-tier value
  (accent) over a short accent underline over a body label. Label boxes are sized to
  their measured wrapped height and the block is vertically centred, so cells never
  overflow. Example `26` (6 KPIs).
- **`chart-slide`** — one captioned chart. Bar charts render as **measured accent
  rectangles** with a value label above and a category label below each bar (caption
  tier, so exempt from the 32 pt floor); each bar's three nodes share a `group_id` so
  the intentional value/bar/label stack is exempt from `E_OVERLAP`/`E_GAP`. Non-bar
  chart types fall back to a single labelled placeholder region. Example `27`.
- **`chart-with-insight`** — the same chart renderer in the left 60 %, with a
  takeaway callout (accent bar + bold text, reusing `_emphasis_stack`) on the right.
  Example `28`.
- **`table-slide`** — a bold header row (brand primary) over a full-width accent rule,
  then a grid of body-tier cells. The rule is the deterministic non-text mark; rows
  are spaced at the 0.3" gap minimum so adjacent rows never trip `E_GAP`. Example `29`
  (3 cols × 4 rows).
- **`metric-comparison`** — 2–3 metrics side by side: a title-tier value (accent), a
  body label, and an optional change delta rendered as a small **accent chip**
  (box + label on top, grouped). Chip width is measured from the delta text. Example
  `30`.

`ChartSlot.type` gained a default (`"chart"`) so a chart can be embedded directly in a
component without restating the discriminator; the existing content-slot union is
unaffected.
