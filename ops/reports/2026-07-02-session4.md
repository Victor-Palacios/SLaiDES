### Commit `a729aeb` — swot items to the caption tier so cell boxes hold a full line (T-064)
**The defect:** SWOT packs four bulleted lists into a 2×2 grid, so each quadrant cell is
short. `_panel_items` sizes each item box `item_h = min(slot_h, max(line_h, wrapped_h))`.
For the 2-item specimen a cell gives `slot_h = 0.45"`, but one body (34pt) leaded line is
`0.567"` — so the `min(slot_h, …)` cap clamped every item box **under one line** (0.45" box
holding a 0.567" line). The render was clean (the emitter doesn't clip to the box and the
shortfall spilled harmlessly into the 0.3" inter-item gap), but the recorded geometry was
**dishonest** — a box that claims less height than its own content.

**Why the earlier "just floor at line_h" idea failed (from session-3 assessment):** flooring
both boxes at a full line needs `2 × 0.567" + 0.3" gap = 1.43"`, but the cell only offers
`~1.2"`. The inter-item gap is the E_GAP floor and each item carries a distinct `group_id`, so
it can't be shrunk. The cell is genuinely too short at body tier — the honest fix had to be
structural.

**The fix (the "smaller item type-tier" option):** swot item text now renders at the
**caption tier** (25pt, `is_caption=True`) instead of body (34pt), via a new
`item_pt`/`is_caption` argument on `_panel_items`. Only the swot caller passes it — the other
callers (`_two_panel_list` → before-after / pros-cons / this-vs-that, and pyramid) keep body
tier untouched. This is **linter-legal**: `E_MIN_BODY_SIZE` explicitly exempts caption-tier
nodes (24–26pt), and swot quadrant items are genuinely dense-grid *secondary* content. At
25pt a leaded line is `0.417"`, which fits inside the `0.45"` cell box — so `item_h` now floors
at a full line honestly, **no content dropped**, and the bold body headings (34pt) still
dominate the tier hierarchy (W_TITLE_HIERARCHY unaffected — caption items only lower
`max_body_pt`).

**Deterministic codification (the durable gate, per the vision-authorization hard rule):**
removed the `swot` exemption from the web-preview geometry guard
(`tests/test_web/test_web_previews.py`), so its one-line-fits (c) invariant now asserts every
swot item box holds its own leaded line. The defect class is now caught **without vision** from
here on; `_GEOMETRY_EXEMPT` is empty.

**Regenerated:** golden `36_swot.json` (item `size_pt: 25` + `is_caption: true` + honest box
